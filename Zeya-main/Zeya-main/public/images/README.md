# /public/images

| File            | Used for                     |
|-----------------|------------------------------|
| `favicon.svg`   | favicon (already at root)    |
| `og-preview.png`| Open Graph social preview — 1200×630. Generate/place one before sharing the site. |
| `door-fallback` *(optional)* | Static fallback backdrop if you later want a photographed door when WebGL is off. |

The CSS fallback door is currently built with gradients in CSS
(`src/styles/global.css`, `.dfb`). A photograph can replace it later.
